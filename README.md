# WorldClock

A timezone comparison app, built natively per platform:

- [`iOS/`](iOS/) — SwiftUI + SwiftData, targeting iOS/iPadOS and macOS. The
  full app, including the hand-drawn "Nocturne" sky illustration. See
  [`iOS/README.md`](iOS/README.md).
- [`Android/`](Android/) — Kotlin + Jetpack Compose. Currently a skeleton:
  city list with live times, add/delete city. See
  [`Android/README.md`](Android/README.md).
